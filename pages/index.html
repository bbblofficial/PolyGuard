چرا Unicollect

یک مدل کافی نیست.

هر متن را چند مدل مستقل می‌خوانند و تصمیم با رأی جمعی گرفته می‌شود؛ پس یک مدلِ بیش از حد مطمئن نمی‌تواند به‌تنهایی کاربر را مسدود کند.

رأی جمعی، نه حدس یک مدل

پنج طبقه‌بند با وزن‌های متفاوت رأی می‌دهند. رأی تنها و تأییدنشده، حداکثر «مشکوک» حساب می‌شود.

فینگلیش را هم می‌فهمد

متن لاتینِ فارسی تشخیص داده می‌شود، به فارسی برگردانده می‌شود و یک‌بار دیگر با سخت‌گیری بیشتر بررسی می‌شود.

هر عدد قابل بررسی است

امتیاز هر مدل، رأی‌ها، مسیر تحلیل و زمان پاسخ در خروجی هست؛ برای لاگ، بازبینی و اشکال‌زدایی.

خروجی

سه نتیجه، یک تصمیم روشن.

فیلد decision همیشه یکی از این سه مقدار است. منطق محصولت را روی همین بنا کن.

ایمن SAFE

هیچ سیگنال معناداری از قوانین رأی‌گیری عبور نکرده. متن را منتشر کن.

مشکوک SUSPECT

سیگنالی هست اما تأیید کافی ندارد. برای بازبینی انسانی نگهش دار.

سمی TOXIC

چند رأی، یا یک رأی قوی که مدل دیگری هم تأییدش کرده. جلوی انتشار را بگیر.

مستندات API

یک درخواست، پاسخ کامل.

بدون SDK و بدون کلید. JSON بفرست و نتیجه‌ی ساختاریافته بگیر. ده مسیر برای بررسی تکی و گروهی، تشخیص زبان، تبدیل فینگلیش، وضعیت مدل‌ها و آمار.

ورود به مستندات محیط آزمایش
curl -X POST "$UNICOLLECT_URL/api/v1/check" \
  -H "Content-Type: application/json" \
  -d '{"text": "سلام، روز خوبی داشته باشی"}'
const res = await fetch(`${UNICOLLECT_URL}/api/v1/check`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    "text": "سلام، روز خوبی داشته باشی"
  })
});
const data = await res.json();
import requests

res = requests.post(
    f"{UNICOLLECT_URL}/api/v1/check",
    json={"text": "سلام، روز خوبی داشته باشی"},
    timeout=180,
)
data = res.json()
