معرفی

Unicollect متن را با پنج مدل طبقه‌بندی بررسی می‌کند و با رأی‌گیری یکی از سه نتیجه‌ی SAFE، SUSPECT یا TOXIC را برمی‌گرداند. همه‌ی درخواست‌ها و پاسخ‌ها JSON با کدگذاری UTF-8 هستند.

آدرس پایه:https://<your-tunnel>.trycloudflare.com
آدرس سرویس با هر اجرا عوض می‌شود. در نمونه‌ها به‌جای $UNICOLLECT_URL همین آدرس پایه را بگذار. مستندات تعاملی خودکار هم روی /docs و /redoc هست.

شروع سریع

یک درخواست POST با فیلد text کافی است. اولین شاخه‌ی منطقت را روی decision بساز.

curl -X POST "$UNICOLLECT_URL/api/v1/check" \
  -H "Content-Type: application/json" \
  -d '{"text": "سلام، روز خوبی داشته باشی"}'
const res = await fetch(`${UNICOLLECT_URL}/api/v1/check`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    "text": "سلام، روز خوبی داشته باشی"
  })
});
const data = await res.json();
import requests

res = requests.post(
    f"{UNICOLLECT_URL}/api/v1/check",
    json={"text": "سلام، روز خوبی داشته باشی"},
    timeout=180,
)
data = res.json()
منطق پیشنهادی
if data["decision"] == "SAFE":
    publish()
elif data["decision"] == "SUSPECT":
    send_to_review()        # بازبینی انسانی
else:  # TOXIC
    block()

احراز هویت و هدرها

نسخه‌ی فعلی کلید API ندارد. برای درخواست‌های POST این هدر لازم است:

هدرها
Content-Type: application/json
Accept: application/json
برای محیط عملیاتی، سرویس را پشت gateway یا لایه‌ی احراز هویت خودت قرار بده. دسترسی مرورگرها از دامنه‌های دیگر (CORS) با متغیر CORS_ALLOW_ORIGINS محدود می‌شود؛ پیش‌فرض همه‌ی دامنه‌هاست.

    فیلدهای پاسخ

    خروجی کامل /api/v1/check. خروجی خلاصه فقط decision، confidence، max_raw، votes_count، total_models، script، fingilish_detected، decided_by و latency_ms را دارد.

    فیلدنوعتوضیح
    decisionSAFE | SUSPECT | TOXICنتیجه‌ی نهایی. اگر تحلیل فینگلیش هم انجام شده باشد، سخت‌گیرانه‌ترین نتیجه.
    confidencenumberمیانگین دو امتیاز بالا بین ۰ و ۱. هرچه بالاتر، سیگنال سمیت قوی‌تر.
    max_rawnumberبیشترین امتیاز خام میان مدل‌ها.
    max_weightednumberبیشترین امتیاز پس از اعمال وزن مدل.
    votes_countintegerتعداد مدل‌هایی که امتیازشان به آستانه‌ی رأی رسیده.
    votesobjectبرای هر مدل: true اگر رأی سمی داده باشد.
    raw_scoresobjectاحتمال سمی بودن از دید هر مدل، بین ۰ و ۱.
    weighted_scoresobjectامتیاز خام ضرب در وزن مدل.
    weightsobjectوزن هر مدل در این تحلیل.
    labels / labels_enobjectنام نمایشی مدل‌ها به فارسی و انگلیسی.
    total_modelsintegerتعداد مدل‌هایی که روی این متن اجرا شدند.
    skipped_modelsarrayمدل‌هایی که به‌خاطر زبان متن اجرا نشدند.
    scriptfa | en | mixedخط تشخیص‌داده‌شده برای تحلیلی که نتیجه را تعیین کرده.
    vote_threshold / min_votesnumberآستانه‌ی رأی و حداقل رأی لازم برای سمی.
    errorsobjectخطای بارگذاری مدل‌ها، اگر وجود داشته باشد.
    fingilish_detectedbooleanآیا متن فینگلیش تشخیص داده شد.
    fingilish_textstring | nullمتن تبدیل‌شده به خط فارسی.
    decided_byoriginal | fingilishکدام تحلیل نتیجه‌ی نهایی را تعیین کرد.
    analysisobjectخلاصه‌ی هر دو تحلیل: original و fingilish.
    latency_msintegerزمان پردازش در سرور، به میلی‌ثانیه.

    خطاها

    مسیرهای نسخه‌ی ۱ کد HTTP درست و بدنه‌ای با این قالب برمی‌گردانند. پیش از خواندن نتیجه، کد وضعیت را بررسی کن.

    پاسخ ۴۱۳
    {
  "error": {
    "code": "text_too_long",
    "message": "text too long (20001 chars, max 20000)"
  }
}
    کد HTTPcodeمعنی
    400empty_textمتن خالی است یا فقط فاصله دارد.
    400empty_batchآرایه‌ی texts خالی است.
    413text_too_longمتن بیش از ۲۰٬۰۰۰ نویسه است.
    413batch_too_largeبیش از ۳۲ متن در یک درخواست گروهی.
    422detailبدنه‌ی JSON نامعتبر است یا فیلد الزامی ندارد (قالب استاندارد FastAPI).
    500internal_errorخطای پیش‌بینی‌نشده در سرور.
    503models_loadingمدل‌ها هنوز در حال بارگذاری‌اند؛ چند ثانیه بعد دوباره تلاش کن.
    503no_models_applicableهیچ مدلی برای این متن قابل اجرا نبود.

    محدودیت‌ها

    • حداکثر طول هر متن: ۲۰٬۰۰۰ نویسه. مدل‌ها فقط ۵۱۲ توکن اول را می‌خوانند.
    • حداکثر ۳۲ متن در هر درخواست گروهی.
    • تعداد پردازش هم‌زمان به تعداد هسته‌های سرور محدود است؛ درخواست‌های اضافه در صف می‌مانند.
    • زمان پاسخ معمولاً زیر نیم ثانیه است؛ timeout سمت کلاینت را دست‌کم ۶۰ ثانیه بگذار.
    • پس از هر استقرار، مدل‌ها چند دقیقه بارگذاری می‌شوند و در این مدت پاسخ 503 می‌گیری.
